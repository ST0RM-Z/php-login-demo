# PHP Login Demo

A small PHP exercise covering session-based login/logout and session security, including a session fixation example.

## Files

- `login.php` / `logout.php` — session-based auth flow
- `session_fixation.php` — demonstrates session fixation
- `db_conn.php` / `dbinit.php` — database connection/setup
- `functions.inc.php` — shared helpers
